Projects Overview

A selection of projects I’ve worked on, including domains, tools, and outcomes.

Invoice Generator
Domain: Business / Retail

A web application that generates invoices and calculates discounts based on customer type and invoice amount. Invoices are stored in JSON files and rendered using server-side templates.

  • Tools Used: Node.js, Express, hbs, environment-based configuration
  • Key Features: dynamic totals, validation, simple reporting
  • Project Outcome: Strengthened understanding of backend logic, request handling, and server-side rendering.
Node.js Express hbs JSON
Library Management System
Domain: Education / Library

A full-stack library management application that supports managing books, authors, and users with CRUD operations and well-structured RESTful endpoints.

  • Tools Used: Java, Spring Boot, Spring Data JPA, MySQL
  • Key Features: book & author management, relational data, controller/service/repository layers
  • Project Outcome: Improved understanding of layered architecture, entities, and database integration.
Java Spring Boot MySQL
Recipe App / Flavor Site
Domain: Lifestyle / Food

A recipe management system with authentication, recipe CRUD, image uploads, categories, and an approval workflow for ingredients and category changes.

  • Tools Used: C#, ASP.NET MVC, Entity Framework, SQL Server
  • Key Features: role-based functionality, validation, and image handling
  • Project Outcome: Experience with larger MVC projects and enforcing business rules in code.
C# ASP.NET MVC Entity Framework
Bug Report / Defect Tracker Exercise
Domain: Quality Assurance

A structured exercise where I practiced filling out defect reports, using consistent fields and workflows commonly seen in tools like JIRA.

  • Tools Used: JIRA-style templates, test cases, screenshots
  • Key Features: clear defect descriptions, steps to reproduce, priorities
  • Project Outcome: Better understanding of defect life cycle and communication between QA and development.
Testing Defect Logging
Secure Product API
Domain: E-Commerce / APIs

A Spring-based application that exposes product endpoints and secures them with authentication and authorization concepts.

  • Tools Used: Java, Spring Boot, Spring Security
  • Key Features: secured endpoints, role-based access, error handling
  • Project Outcome: Practical experience with basic security configuration and protected API routes.
Spring Security REST API
REST API & JavaScript Mini Projects
Domain: Practice / Learning

Smaller exercises focused on building REST endpoints and improving JavaScript skills such as DOM manipulation and basic UI components.

  • Tools Used: ASP.NET MVC, C#, JavaScript, fetch API
  • Key Features: client-side interactions, dynamic content, simple APIs
  • Project Outcome: Improved comfort with front-end scripting and integrating front and back ends.
REST ASP.NET JavaScript
