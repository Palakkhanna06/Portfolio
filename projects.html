Projects Overview

Builds spanning data analytics, real-time multiplayer, backend APIs, full-stack MVC—and disciplined delivery with GitHub and Jira.

HR Attrition Data Analytics
Domain: Analytics / Workforce

End-to-end analysis of HR attrition data to surface actionable insights. I modeled the data with pivot-style breakdowns (dimensions and aggregates), iterated on hypotheses, and packaged results in an interactive dashboard that refreshed as inputs changed.

  • Tools Used: Python, pivot-oriented analysis workflows, dashboard tooling
  • Key Features: insight discovery, exploratory metrics, live working dashboard, repeatable data views
  • Project Outcome: Demonstrated translating raw HR data into clear charts and decisions stakeholders can rely on—not just notebooks, but something useable.
Python Data analysis Dashboards Pivot logic

Card Pairs Multiplayer Game
Domain: Real-Time Web / Gaming

A multiplayer card matching experience where exactly two players can join across the network. The server pushes game state live over WebSockets, and a sidebar chat stays in sync while both clients play from their own browsers.

  • Tools Used: WebSockets for real-time state, networked session handling, concurrent client UI
  • Key Features: two-player match flow, fairness of turns, reconnect-friendly messaging basics, contextual side chat during play
  • Project Outcome: Practiced reasoning about latency, broadcasts, room-like sessions, and multiplayer UX—all without fighting the abstraction of plain HTTP polling.
WebSockets Real-time Multiplayer
Flavor Garden
Domain: Hospitality / Restaurant Ops

Restaurant operations platform modeled in Java Spring Boot against a disciplined MySQL schema (designed with MySQL Workbench). Guests and operators work through cohesive screens for floor plans: seating layouts, hosted events, curated menus plus menu items, reservations and booking windows, transactional email notifications—all behind clean REST endpoints.

  • Tools Used: Java, Spring Boot, MySQL Workbench / relational modeling, REST controllers, transactional mail integration
  • Key Features: table & seating management, event scheduling, layered menu catalogues, bookings with availability checks, outbound mailers for confirmations/reminders
  • Project Outcome: Produced a believable SaaS-lite domain model with guarded boundaries between domain services, cohesive UI polishing, and API contracts other clients could consume.
Spring Boot REST APIs MySQL Workbench Email
